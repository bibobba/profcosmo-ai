# EPICA swatches — flat folder

All 165 swatch images are in this one folder, with unique filenames encoding source page, shade group and code.

- Copy the entire `epica` folder into the repository at `public/palette/epica/`.
- `palette.json` and `palette.csv` are indexes; image crops preserve the source swatches.
- Check code/crop boundaries against the original PDF before production.
